## 精选项目（Featured Projects）

### [OpenFinance](https://github.com/MorikawaSouma/OpenFinance)

> 一个面向量化研究与风控演练的全栈工作台（monorepo）。后端基于 FastAPI，提供因子计算、策略回测、风控审批与 SSE 实时事件流；前端基于 Next.js，支持 Chat、Pipeline、Tasks、Reports 等完整工作流。支持离线运行（LLM stub 模式）。

**技术栈**：`Python` · `FastAPI` · `Next.js` · `TypeScript`

### [TOEFL-Vocab-SRS](https://github.com/MorikawaSouma/TOEFL-Vocab-SRS)

> 一个面向 TOEFL iBT / TPO 阅读词汇的本地间隔复习（SRS）网页应用（类 Anki）。纯前端实现，数据存储于浏览器本地，支持英→中识别与中→英拼写两种复习模式，并内置 AI 助教（DeepSeek 多轮问答）与薄弱项统计。

**技术栈**：`JavaScript` · `jQuery` · `TailwindCSS` · `HTML`
