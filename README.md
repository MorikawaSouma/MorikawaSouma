## 精选项目（Featured Projects）

### OpenFinance

面向量化研究与风控演练的全栈工作台（monorepo），包含 FastAPI 后端（因子计算、策略回测、风控审批）与 Next.js 前端工作台。支持离线运行（LLM stub），无需预先配置大模型 Key。

- 技术栈：Python · FastAPI · Next.js · TypeScript
- 仓库：https://github.com/MorikawaSouma/OpenFinance

### TOEFL-Vocab-SRS

面向 TOEFL iBT / TPO 阅读词汇的本地间隔复习（SRS）网页应用（类 Anki）。纯前端，数据本地优先，支持 AI 助教多轮问答与薄弱项分析。

- 技术栈：HTML · TailwindCSS · jQuery · JavaScript
- 仓库：https://github.com/MorikawaSouma/TOEFL-Vocab-SRS
